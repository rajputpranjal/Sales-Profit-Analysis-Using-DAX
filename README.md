# Sales-Profit-Analysis-Using-DAX
An interactive business intelligence dashboard built using Microsoft Power BI, showcasing advanced DAX (Data Analysis Expressions) calculations to analyze sales, profit, and product performance.

# Project Overview

This project focuses on leveraging DAX functions to extract meaningful insights from sales data. The dashboard highlights profit trends, quantity distribution, and product-level performance to support data-driven decision-making.


# Key Features

Profit Analysis

Total Profit: 21,575

Profit calculated using DAX measures



Quantity Insights

Maximum Quantity: 100.50


 
DAX-Based Calculations

Custom measures using SUM, MAX, COUNT

Quick Measures for dynamic insights


 
Product-Level Analysis

Profit by Quantity per product

Top-performing products (e.g., Dhokla, Jalebi)


 
Customer/Name Analysis

Max quantity per individual

Performance comparison

# DAX Functions Used

SUM() → Calculate total profit

MAX() → Find maximum quantity

COUNT() → Count total orders

CALCULATE() → Modify filter context

Quick Measures → Auto-generated DAX
